# To-Do List CLI App

A persistent command-line to-do list manager built with Python.

## Features
- View, Add, and Remove tasks
- Tasks are persistently stored in a `tasks.txt` file so they are saved between sessions.
- Interactive and simple command-line interface

## How to Run
1. Ensure Python is installed.
2. Run the script from your terminal:
   ```bash
   python todo.py
   ```
