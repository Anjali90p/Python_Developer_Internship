# Flask Portfolio Website

A personal portfolio website built with Python, Flask, HTML, and CSS. 
Designed with modern aesthetics, glassmorphism, and dynamic hover effects.

## Features
- **Flask Routing:** Serves dynamic content and processes form submissions.
- **Aesthetic UI:** Uses CSS variables, dark mode styling, and Google Fonts (`Outfit`).
- **Contact Form:** Receives messages and displays dynamic flashed feedback using Flask's `flash()`.
- **Responsive Layout:** Works smoothly on different screen sizes using CSS Grid and Flexbox.

## Project Structure
- `app.py`: Main Flask application handling routes.
- `templates/index.html`: The HTML template.
- `static/css/style.css`: Styling for the portfolio.

## How to Run

1. Make sure Flask is installed:
   ```bash
   pip install Flask
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open a browser and visit `http://127.0.0.1:5000/`.
