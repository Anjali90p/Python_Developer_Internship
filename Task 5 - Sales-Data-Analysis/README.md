# Sales Data Analysis

A basic data analysis project using Python, Pandas, and Matplotlib.

## Features
- Loads sales data from a CSV file (`sales_data.csv`).
- Groups data by Region and Product using `groupby()`.
- Calculates total sales using `sum()`.
- Generates and saves visual charts (`sales_analysis_chart.png`) using `plot()`.

## Requirements
- Python 3
- `pandas`
- `matplotlib`

## How to Run
1. Install dependencies:
   ```bash
   pip install pandas matplotlib
   ```
2. Run the analysis script:
   ```bash
   python analysis.py
   ```
3. View the generated `sales_analysis_chart.png` in the directory to see the plotted charts.
